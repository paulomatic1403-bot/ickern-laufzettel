# Laufzettel Athletik · Westfalenauswahl Ickern

Interaktiver Laufzettel für die Athletikeinheiten der WTV Westfalenauswahl (U9 bis U13).

* Enthält keine Namen oder Daten von Kindern. Der Kader wird im Browser gespeichert oder aus dem privaten Daten-Repo geladen.
* Speichert jede Einheit automatisch im Browser.
* Export als Text, JSON oder direkt als Datei in das private Daten-Repo (Fine-grained Token, nur auf dem Gerät gespeichert).
